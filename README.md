# Tsamaya legal pages (moved)

The privacy policy and terms of use for the Tsamaya app live on the main site:

- https://tsamayaapp.co.za/privacy.html
- https://tsamayaapp.co.za/terms.html

They are generated from the app repo's `legal/` folder. The pages in this repo
only forward there (with a canonical link), so builds that still link to
safenavjhb.github.io/tsamaya-legal land on the current versions and no stale copy
stays indexed.
